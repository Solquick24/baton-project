## 5. 시연 순서(두 경로)

**이어받기 경로**(약 4분)
1. B 로그인 → 홈(02) 다음 진료 카드 → 질문(08)에서 '질문 정리하기' → 브리핑 만들기 → 브리핑(09) 확인.
   시간이 없으면 `npm run seed -- --pregenerate`로 통합·브리핑을 미리 만들어 두고 09부터 시작.
2. 진료 기록(15): `fixtures/audio`의 가상 음성 올리기 → 변환(실패 시 저장된 전사로 대체, 배지 표시) → 메모 "혈압약 아침 반 알 그대로. 다음 진료 4월 9일 10시." → 정리하기.
3. 검토(18): B는 schedule·companion 블록만 보고 공유하기 → C·A의 다음 조회에 공개.
4. 환자 또는 A로 전환 → 확인 필요(19): ob_01 vs rx_im_02 두 근거와 차이, 처리 3가지 → '병원에 확인'(awaiting_confirmation) 또는 '메모 고치기'(아침으로 고치면 resolved).
5. (선택) 메모에 `혼입 시연`을 넣고 다시 정리 → blocked, 공유 버튼이 409로 거부되는 것을 보여준다.

**범위 경로**(약 2분)
1. 환자 로그인 → 설정(25) → 박지후 → 25-2에서 동행 → 일정만 저장.
2. B로 전환 → 홈·타임라인이 23 화면처럼 바뀜(약·요약 없음, 잠금 표시 없음).
3. B 토큰으로 `PUT /members/u_b/scope` 직접 호출 → 403. 공유 기록에 변경 1건.
4. 환자로 돌아가 B를 동행으로 복구.

두 경로 동안 AI provider 호출 횟수는 생성 버튼을 누른 횟수와 같아야 하고, 조회·범위 변경으로는 늘지 않아야 한다(SC-004).
