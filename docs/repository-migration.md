# 바통 대회 저장소 마이그레이션 기록

기존 `https://github.com/Solquick24/baton-prework`의 이력을 보존하여 새 `https://github.com/Solquick24/baton-project`로 옮긴다. 새 레포는 확인 당시 비어 있었으며, 사용자는 아직 대회 플랫폼에 등록하지 않았다고 확인했다. 따라서 이번 준비에서는 로컬 문서·커밋과 원격 설정만 준비하고 새 레포에 push하지 않는다.

기존 커밋을 squash·rebase·amend하거나 날짜를 변경하지 않는다. 기존 미커밋 PRD·제출안 기록·README 변경도 이전 준비 커밋에 포함한다. 실제 자격 증명과 `.aws/`, `.codex/`, `.env`, 의존성·빌드 결과는 제외한다. 참가 가이드 PDF 원본은 이 저장소에 복사하지 않으며 요약과 원본 해시만 남긴다.

## 로컬 원격 설정

- `origin`: `https://github.com/Solquick24/baton-project.git`
- `prework`: `https://github.com/Solquick24/baton-prework.git`
- 브랜치: `main`
- 현재 작업 디렉터리 이름 `baton-prework`와 npm 패키지 이름은 기존 상태를 유지한다. 폴더 이름은 push 대상과 무관하다.

## 빈 저장소 등록 후 실행

1. 코드와 커밋 이력이 없는 새 레포 URL을 대회 플랫폼에 등록한다. 기본 브랜치 `main` 및 운영진 열람 권한을 확인한다.
2. 등록 완료 후 준비한 전체 이력을 새 레포에 반영한다.

   ```bash
   git push -u origin main
   ```

3. GitHub에서 기본 브랜치가 `main`인지, 이전 커밋과 공개 문서가 보이는지 확인한다. 새 레포에 다른 커밋이 생겼다면 force push하지 않고 먼저 상태를 검토한다.
4. 이후 대회 작업은 같은 레포를 계속 사용한다. 17:00 KST 전에 main 반영과 플랫폼 제출을 모두 완료한다.

현재 단계는 **등록 전 로컬 준비**다. 원격 마이그레이션 완료는 실제 push와 GitHub 상태 확인 후 기록한다.
