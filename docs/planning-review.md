## 미정 항목 처리 원칙

- 인프라·공유 시점은 사용자 답변으로 확정했다: 로컬 서버·SQLite·시드 로그인에 AI만 AWS, 검토 후 공유하기.
- 동행의 watch/prep·불일치 상세는 기본 full. needsCheck 상태만 낮은 블록에 둔다.
- 약 이름은 기존 companion.medChanges 범위를 유지하되 진단 추론 방지를 보장하지 않는다.
- 지도 제공자·모델 ID는 사실 검증 없이 확정하지 않는다. 저장된 가상 결과로 로컬 검증이 가능해야 한다.
- 실시간 자막·번역·법률 검토·AWS 배포는 핵심 구현 작업에 넣지 않는다.
- 문서·작업 목록 생성만 진행하며 애플리케이션·테스트·배포 코드는 작성하지 않는다.

## 추가 충돌 해소

B(companion)의 인수인계와 full 전용19번 불일치 상세를 같은 계정으로 완주할 수 없다.
B는변경·질문·허용내용 검토를 시연하고 상세비교는환자/A로전환하도록 계획·명세·데모를 맞췄다.
헌장의 AWS 기본 방향은 이번 사용자 승인 로컬데모에 한정한 기술 예외를 기록했다.
