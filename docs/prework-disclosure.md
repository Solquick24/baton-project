## 구현되지 않은 부분

가져오기 기준에 React 화면·라우팅, Fastify 서버·HTTP 핸들러, 공유 런타임 스키마, SQLite DB·시드 계정·인증·권한 처리는 구현되어 있지 않다. Bedrock·Transcribe 호출, AI 프롬프트·출력 검증·작업 실행, 음성·문서 업로드와 요약·브리핑·질문 통합도 구현되어 있지 않다.

가져오기 기준의 `fixtures/`에는 README와 빈 자리만 있었으며, 완성된 가상 음성·문서·시드·정답 데이터셋을 가져오지 않았다. 실행 가능한 E2E·평가 스크립트나 검증 결과, 배포된 앱·AWS 자원도 포함하지 않았다. `tasks.md`의 68개 구현 작업은 모두 미완료다. 사전 제출안에 적힌 준비 자료 목록은 계획 설명이며, 실제로 존재하는 완성 자료 목록과 동일하지 않다.
